# Cargills Online Manual Testing Project

## Project Overview

This project demonstrates a complete **Manual Testing Process** conducted on the **Cargills Online Website**. The objective of this project is to validate the functionality, usability, and reliability of the system through structured testing practices.

The testing process includes **Test Scenarios, Test Cases, Test Execution Reports, Bug Reporting, and Test Evidence** to simulate a real-world QA workflow.

---

## Website Tested

**Application Name:** Cargills Online  
**Type:** E-Commerce / Online Grocery Platform  
**Testing Type:** Manual Testing

---

## Project Objectives

The main objectives of this testing project are:

- Verify core functionalities of the website
- Validate user workflows and system behavior
- Identify defects and usability issues
- Ensure smooth customer experience
- Improve software quality through systematic testing

## Test Deliverables

The following QA documents are included in this repository:

### 1. Test Scenarios
Contains high-level testing scenarios covering different modules of the application.

### 2. Test Cases
Contains detailed manual test cases with:
- Test Case ID
- Module
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Status

### 3. Test Execution Report
Contains execution status of all test cases.

### 4. Bug Reports
Documents defects identified during testing with severity and priority.

### 5. Test Evidence
Contains screenshots of executed test cases and identified issues.
